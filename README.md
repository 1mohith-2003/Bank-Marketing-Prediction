# Bank Marketing Campaign Prediction

A Machine Learning project that predicts whether a bank customer will subscribe to a term deposit based on customer information, financial details, campaign information, and previous campaign history.

---

## Project Overview

The objective of this project is to build a binary classification model that predicts whether a customer will subscribe to a bank term deposit.

The target variable is:

- `yes` → Customer subscribed to the term deposit
- `no` → Customer did not subscribe

The project follows an end-to-end Machine Learning workflow:

1. Data Understanding
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Building
6. Model Evaluation
7. Hyperparameter Optimization
8. Threshold Optimization
9. Model Saving
10. Streamlit Deployment

---

## Problem Statement

Banks conduct marketing campaigns to promote term deposit products to their customers.

However, contacting every customer can be inefficient and expensive.

This project aims to build a Machine Learning model that predicts the probability of a customer subscribing to a term deposit.

The prediction can help banks:

- Identify high-potential customers
- Improve marketing campaign efficiency
- Reduce unnecessary customer contacts
- Prioritize customers for targeted campaigns
- Improve campaign conversion rates
